# 004 - Docker and Deploying Portainer

## Goal

Learn the basics of Docker and deploy Portainer to manage containers on my Raspberry Pi.

## Hardware Used

* Raspberry Pi 4

## Software Used

* Docker
* Portainer

## Challenges

* I didn't understand the difference between images, containers, and volumes.
* My first Portainer setup didn't work correctly.
* I had to remove the container and redeploy it the right way.

## What I Learned

* A Docker image is a template used to create containers.
* A container is a running instance of an image.
* Volumes allow data to stay saved even if a container is removed.
* Ports allow applications running in containers to be accessed from a browser.
* Restart policies can automatically start containers after a reboot.
