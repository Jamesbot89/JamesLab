# 005 - Monitoring My Homelab with Uptime Kuma

## Goal

Learn how monitoring works and track the health of services running in my homelab.

## Hardware Used

* Raspberry Pi 4

## Software Used

* Docker
* Uptime Kuma

## Challenges

* I had never used a monitoring platform before.
* I needed to understand the difference between Ping monitoring and HTTP monitoring.
* I wasn't sure how uptime percentages and response times worked at first.

## What I Learned

* Ping monitoring checks whether a device is online.
* HTTP monitoring checks whether an application is responding.
* Response time measures how quickly a service responds.
* Uptime percentage tracks service availability over time.
* Monitoring helps identify problems before I notice them manually.
