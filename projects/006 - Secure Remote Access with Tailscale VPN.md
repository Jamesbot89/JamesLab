# 006 - Secure Remote Access with Tailscale VPN

## Goal

Learn how VPNs work and securely access my homelab from anywhere.

## Hardware Used

* Raspberry Pi 4
* Smartphone

## Software Used

* Tailscale

## Challenges

* I didn't fully understand the difference between local and remote network access.
* I needed to learn why private IP addresses only work inside my home network.
* I wanted a secure way to access my homelab without exposing services directly to the internet.

## What I Learned

* Private IP addresses are only reachable from inside the local network.
* VPNs create secure tunnels between devices across the internet.
* Tailscale uses WireGuard technology for secure communication.
* Remote access can work without opening ports on the firewall.
* I can securely manage my homelab from my phone or another device while away from home.

* Learn more about WireGuard and VPN technologies.
